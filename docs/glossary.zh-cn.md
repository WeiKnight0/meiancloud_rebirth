# 术语表

[English](glossary.md) | [简体中文](#)

| 术语 | 定义 |
|---|---|
| **梅庵** | 东南大学校园内的历史建筑，1915 年为纪念李瑞清而建。现为文化遗产保护单位，也是本项目的名称来源。 |
| **梅庵云迹** | 网站项目名称。以数字化方式展示梅庵历史、文化与教育意义的平台。 |
| **红色文化** | 与中国共产主义运动相关的革命文化与历史。梅庵是早期马克思主义教育和共产主义青年团活动的重要场所。 |
| **东南大学** | 位于南京的知名高等学府。梅庵位于其四牌楼校区。 |
| **李瑞清** | 字梅庵，两江师范学堂监督（校长），教育家、书法家。梅庵建筑以其号命名。 |
| **团二大** | 中国社会主义青年团第二次全国代表大会，1923 年 8 月在梅庵召开。青年运动史上的重要里程碑。 |
| **至善讲解团** | 东南大学的志愿者讲解团队，负责梅庵的参观管理和预约接待。 |
| **Swiper** | 首页图片轮播使用的 JavaScript 轮播库。 |
| **Gunicorn** | Python WSGI HTTP 服务器，生产环境用于运行 Django 应用。 |
| **CSRF** | 跨站请求伪造。Django 的 CSRF 保护要求在状态变更请求中携带令牌。 |
| **Session** | Django 的服务端会话机制，用于在多次请求间维持用户登录状态。 |
| **UserProfile** | 项目自定义的用户资料模型，扩展 Django 内置 `User`，添加头像、昵称、性别、生日和签名字段。 |
| **Comment** | 项目的讨论模型，通过自关联外键同时支持顶级评论和层级回复。 |
| **is_checked** | `Comment` 的审核标志。为 `False` 时评论不对外显示，超级管理员通过设为 `True` 审核通过。 |
| **Prefetch** | Django ORM 优化手段，单次查询获取关联对象，用于避免评论列表的 N+1 查询问题。 |
